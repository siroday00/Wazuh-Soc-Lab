# 🛡️ Wazuh SOC Lab

## 📌 Overview
The **Wazuh SOC Lab** is a hands-on cybersecurity environment built to simulate real-world Security Operations Center (SOC) workflows. It uses Wazuh SIEM to monitor endpoints, detect threats, analyze logs, and investigate security incidents in a controlled lab setup.

## 🎯 Objectives
- Centralize and analyze security logs
- Detect suspicious activities and security threats
- Perform incident investigation and response
- Understand SIEM and SOC workflows in practice
- Strengthen cybersecurity monitoring skills

## 💻 Lab Requirements / Prerequisites
Before setting up the lab, you need to install the following:

- :contentReference[oaicite:0]{index=0} (or any hypervisor)
- :contentReference[oaicite:1]{index=1} (for Windows endpoint)
- :contentReference[oaicite:2]{index=2} (for Linux endpoint)

These virtual machines will be used as endpoints for log collection and security monitoring.

## 🧪 Lab Environment
This lab is built using:
- Wazuh Manager (SIEM Platform)
- Wazuh Agents installed on Windows and Linux endpoints
- Wazuh Dashboard for visualization and monitoring
- System, authentication, and security logs

## 🚨 Simulated Use Cases
- Brute-force login attempts detection (SSH/RDP)
- Unauthorized access and privilege escalation
- File integrity monitoring
- Suspicious process execution
- Malware behavior detection

## 🛠️ Skills Gained
- Security event monitoring and analysis
- Alert triage and prioritization
- Log investigation and correlation
- Incident response fundamentals
- SOC analyst workflow experience

## 🚀 Getting Started
1. Install VMware Workstation Player
2. Download Windows ISO and Ubuntu Desktop ISO
3. Create and configure virtual machines
4. Install Wazuh Manager
5. Deploy Wazuh Agents on endpoints
6. Access Wazuh Dashboard
7. Start monitoring security events

## 📊 Outcome
This lab demonstrates practical SOC operations and improves hands-on skills in security monitoring, threat detection, and incident response using Wazuh.
